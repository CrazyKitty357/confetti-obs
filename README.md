# confetti-obs

a basic website that can be flung into a browser source to play confetti

---

there are 2 versions of the same website that work differently

[defaut](https://crazykitty357.github.io/confetti-obs/) which shows the confetti when the page loads  
[onclick](https://crazykitty357.github.io/confetti-obs/onclick.html) which will play the confetti animation when the user clicks


### RESOURCES USED
[confetti.js](https://github.com/swetzel/confetti.js) for the confetti
